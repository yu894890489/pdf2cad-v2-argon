# pdf2cad-v2-argon — 输电铁塔横担层 CAD 图纸解析、单线图反算补全与三维多面体组装引擎

本项目面向输电铁塔横担层 CAD 矢量图纸（PDF），提供从**表格提取、结构图元分类、四层拓扑构建、尺寸示意图数学核算、单线图（1:100）基准反算补全/截断**到**三维多面体（`1→3→4→2` 四棱台柱体）自动折起合龙与交互式点边输角度拼装**的全流程自动化解析引擎。

## 一、 核心功能与八阶段流水线架构

1. **阶段 1 — 明细表与单线图基准提取 (`extract_tables_from_pdf`)**
   - 自动解析图纸右侧《构件明细表 (BOM)》与《螺栓、脚钉、垫圈明细表》，输出结构化数组。
   - 自动识别左上角《单线图 (1:100)》整体控制尺寸（底面跨度 `7000mm/8000mm`、根部高 `2500mm`、腰部高 `600mm`、根部底宽 `3364mm`、根部顶宽 `2988mm`、外侧尖角端宽 `1000mm`、预拱度 `55mm/65mm`）。

2. **阶段 2 — 结构图面分区与矢量图元分类 (`classify_view_region`)**
   - 自动将图纸划分为独立结构图面：`上平面结构图 (顶面)`、`前/后立面结构图 (主视图)`、`下平面结构图 (底面)`、`1-1 / 2-2 / 3-3 / 4-4 横隔面断面图`、`5-5 挂线板断面图`及`垫块大样图 (1:5)`。
   - 按材料规格自动分类图元：
     - `Q345L / Q420L / Q355L / L`：等边角钢杆件（区分主材角钢、斜腹杆角钢、横隔面角钢）
     - `Q345Ø / Q355∅`：无缝钢管/挂线衬管杆件
     - `Q345- / Q420- / -t`：节点连接板、加厚挂线板（`-22`）及填板/垫块（提取闭合多边形轮廓）
     - 孔位图元：`M16 / M20` 螺栓孔群、双帽防松螺栓孔、`Ø38` 挂线孔、`Ø30` 施工孔及 `3Ø20` 跳线孔

3. **阶段 3 — 四层空间拓扑关系构建**
   - 通过圆圈引线追踪（支持 `前XXX / 后XXX` 共用引线及正交折线引线）建立四层拓扑图：
     `① 一面面结构图分区` $\rightarrow$ `② 杆件与杆件交汇联系` $\rightarrow$ `③ 节点连接板多边形包络` $\rightarrow$ `④ 螺栓孔位归属映射`。

4. **阶段 4 — 尺寸示意图（三角形/多边形）与 BOM 交叉审核**
   - 提取图面尺寸示意图，采用托勒密等腰梯形对角线定理 $D=\sqrt{S^2+W_1\cdot W_2}$、余弦定理邻补角闭合、预拱倾角修正及端头缩进公式 $L_{\text{BOM}} = L_{\text{理论}} + \Delta_1 + \Delta_2$ 对 BOM 长度与 GB/T 706 理论单重进行交叉核验。

5. **阶段 5 — 三维构件实体重建 (`reconstruct_3d_angle_bars` & `reconstruct_plate_polygons`)**
   - 角钢杆件：按 BOM 肢宽 $B$ 与肢厚 $t$ 构建无扭转正交基（`makeBasis`）双肢 L 型三维角钢实体。
   - 连接板：按识别的闭合多边形顶点与板厚 $t$ 拉伸生成三维多边形钢板实体。

6. **阶段 6 — 多面体闭合判定与 `1→3→4→2` 空间四棱台组装 (`verify_polyhedron_closure`)**
   - **单图/多图闭合检核**：先判断单张图纸能否组成闭合多面体，支持多张图纸联合上传解析整层横担。
   - **件号闭环追踪 (`1→3→4→2`)**：从正视图（垂直地面 $90^\circ$）上边1（`#303/#403`）、下边2（`#301/#401`）出发 $\xrightarrow{90^\circ}$ 顶面（上平面）连接边3（`#304/#404`） $\xrightarrow{90^\circ}$ 平行背面（由 `前/后` 标注自动分离的平行后立面）连接下边4（`#302/#402`） $\xrightarrow{90^\circ}$ 底面（下平面）回到正视图下边2，闭合成**塔身连接侧更宽、外侧呈尖角**的四棱台多面体。
   - **共用杆件重合与去重**：当相邻两个面组合时，共用棱边上的同一杆件三维坐标 100% 重合且自动去重保留单根。
   - **按面显示件号三维标牌**：支持点击哪面显示哪面的三维件号标牌，避免同时显示遮挡视线，并支持一键显隐与无级放大缩小。
   - **自由摆放与点边输角度连接**：支持将所有结构面放入 3D 窗口人工自由拖拽摆放，或点击任意两条边界棱边输入夹角（如 `90°`/`-90°`/`0°`）精确铰接组合。

7. **阶段 7 — 单线图标准尺寸核对与反算补全/截断 (`backcalculate_view_completions_from_single_line`)**
   - 以单线图（1:100）为整体尺寸标准，核对各边主材件号 + 端套/根部短角钢/节点板延伸长度。
   - 自动检测主结构视图3（横担层底面）等视图的尺寸缺漏，用**亮绿色 (`#00ff88`)** 标示反算补全段（根部端套外伸段、外侧尖角收口段、遗漏菱形斜撑及端头缩进段），用**洋红色 (`#ff2a85`)** 标示超包络截断段，支持回查调整 2D 原图并一键将补全模型直接放置到 3D 多面体对应面上。

## 二、 环境安装

```bash
pip install -r requirements.txt
```

## 三、 快速运行与测试新图纸

将单张或多张横担层 CAD 矢量 PDF 图纸传入 `tower_crossarm_cad_pipeline.py` 即可执行全流程解析与单线图反算核验：

```bash
# 解析单张或多张 CAD 图纸并输出结构化核验报告 JSON
python3 tower_crossarm_cad_pipeline.py drawing_04.pdf drawing_05.pdf --out-json pipeline_test_report.json
```

- `requirements.txt`：Python 运行环境依赖清单
